# SecureLog — Розумна захищена система пріоритетної реплікації журналів подій

Командний семестровий проєкт з дисципліни «Алгоритми і оптимізація програмних рішень».

## Структура репозиторію

- `src/` — основні проєкти (Core, Compression, DP, ML, Security, App)
- `tests/` — тести (C1, D1, Unit)
- `docs/` — документація, конспекти, ролі, граф залежностей
- `build/` — скрипти збірки
- `artifacts/` — результати збірки (не комітяться)

## Як зібрати

```bash
dotnet build
