# Граф залежностей задач

## Легенда

- `→` — залежність (від попередника до наступника)
- `[B]` Basic, `[A]` Advanced, `[E]` Expert

## Критичний шлях

T1.1 → T1.2 → T2.1 → T4.1 → T5.5 → T5.6 → T6.x

Якщо затримати будь-яку задачу на цьому шляху — затримається весь проєкт.

## Паралельні гілки

### Гілка 1 — Інфраструктура
T1.1 → T1.2 → T1.3
              ↓
             T1.4
              ↓
             T1.5

### Гілка 2 — Стиснення
T1.2 → T2.1 → T2.2 → T2.3

### Гілка 3 — ДП
T1.4 → T2.4 → T2.5 → T2.6

### Гілка 4 — Машинне навчання
T1.4 → T3.1 → T3.2 → T3.3 → T3.4

### Гілка 5 — Планування реплікації
T2.4 + T2.5 → T3.5

### Гілка 6 — Захист
T1.2 + T2.1 → T4.1 → T4.2

### Гілка 7 — Генетичний алгоритм
T3.1 + T2.4 → T4.3 → T4.4 → T4.5

### Гілка 8 — Атаки
T4.1 + T4.3 → T5.1
T4.1 → T5.2
T4.1 → T5.3
T4.1 → T5.4

### Гілка 9 — Фінальне складання
T2.1 + T2.4 + T3.1 + T3.5 + T4.1 + T4.3 → T5.5 → T5.6 → T6.1–T6.6

## Точки стикування

- **T3.5** залежить від T2.4 + T2.5
- **T4.1** залежить від T1.2 + T2.1
- **T4.3** залежить від T3.1 + T2.4
- **T5.5** залежить від усіх попередніх
